# 4Runner – Replace Roof Rack and Ladder

## Definition of Done
Old roof rack and ladder removed from 4Runner, roof bolt holes sealed, new roof rack installed (or holes permanently sealed if running rackless), old rack and ladder sold.

## Status
Old rack and ladder removed. Currently running rackless. **Roof bolt holes are open and leaking water into the cabin** — discovered 2026-06-12 after a car wash. All four corners of the interior got wet.

## Next Actions — URGENT
- [x] Remove old roof rack from 4Runner
- [x] Remove ladder from 4Runner
- [ ] **Seal roof bolt holes** — water is leaking into the cabin through the open mount holes. See fix options below.
- [ ] **Dry out interior** — standing water in headliner/pillars will cause mold, smell, and wiring corrosion
- [ ] Decide: install new roof rack or run rackless permanently
- [ ] If rackless: seal holes permanently with bolts + silicone RTV + rubber washers
- [ ] If new rack: install new rack (mounts will re-seal the holes)
- [ ] Sell ladder (buyer found)
- [ ] Wan Ting to list old roof rack for sale

### Seal options
1. **Quick fix** — put original bolts (or matching stainless steel bolts) back in with rubber washer + silicone sealant under the head. Clean look, waterproof, reversible.
2. **Permanent rackless** — bolts + RTV silicone + rubber washers. Same thing but with more sealant since you're not planning to pull them again.
3. **New rack** — installing the new simpler rack will re-seal the holes with its own mounting hardware.
