# Home – Mount Dining Room Light

> **Parent project:** [[Home – Remodel – Finish]]

## Goal
Mount the new light fixture in the dining room ceiling.

## Context
- Ceiling has a single round junction box with a bare bulb currently installed
- New fixture has a long rectangular backplate with two mounting brackets spaced far apart
- Need to bridge the single junction box to the fixture's two mount points

## Steps
- [ ] Check fixture hardware bag for an included crossbar/mounting strap bracket
- [ ] If no crossbar included, buy a universal mounting bracket (~$3 at Home Depot/Lowe's)
- [ ] Turn off power at breaker
- [ ] Remove existing bare bulb and socket
- [ ] Install crossbar bracket into junction box screw holes
- [ ] Wire fixture (match black-to-black, white-to-white, green ground to green pigtail)
- [ ] Mount fixture backplate to crossbar bracket
- [ ] Restore power and test
