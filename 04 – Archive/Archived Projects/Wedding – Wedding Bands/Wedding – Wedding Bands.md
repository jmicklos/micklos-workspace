## Jonathan's Band

### STYLE DIRECTION UPDATED 2026-06-12 — tall, pronounced bevel
After in-person try-ons, the look Jonathan wants is a **tall / high-profile band with a pronounced beveled edge** — raised crown, architectural cross-section. The **David Yurman Beveled Band** was the reference piece ("very, very pronounced beveled edge, it's very tall and I like that a lot"). This **supersedes** the earlier low-rounded "dad band" dome framing. Key distinction: he wants *height*, not just cut corners. Blue Nile's classic dome read as "not as tall" by comparison. Industry term for the raised profile = **"European / Euro dome."**

- **Style:** Tall raised profile with pronounced beveled edges, yellow gold, no diamonds/ornamentation. Brushed-center + polished-bevel two-tone is acceptable.
- **Preferred width:** **7mm** (DY only makes 6mm and 8.5mm — no 7mm — so a 7mm in this look means going non-DY anyway)
- **Ring size: 9.5** (confirmed 2026-06-19 — use for ordering; free resizing as backstop)
- **Width → size (earlier estimates):**
  - 6mm → ring size 8.75
  - 7mm → ring size TBD (try on / use free resizing)
  - 8mm → ring size 9
- **Material: 18K yellow gold — DECIDED 2026-06-12.** Reverses the earlier 14K lean. Reason: **heft is now an explicit priority.** 18K is 75% gold vs 14K's 58% → denser/heavier and richer color. Tradeoff accepted: 18K is softer (scratches easier) and pricier, but the weight + color win for this ring.
- **HEFT is a buying criterion.** Jonathan wants a *substantial, heavy* ring. How to ensure it before buying online:
  - **Ask for the finished gram weight in his size.** Benchmarks for a chunky men's band: ~6–9g = light, 10–14g = solid, **15g+ = serious heft (DY-tier feel).** Get grams before/at purchase; a seller who won't give it = yellow flag.
  - **Standard/flat fit, NOT comfort fit** — comfort fit hollows the interior, removing grams. Standard fit = more metal = more heft (and cheaper). Aligns with "comfort fit not required."
  - **Tall profile also adds grams** — so the raised-crown look and the heft goal reinforce each other. Gram weight doubles as a check that the profile is genuinely tall, not flat.
  - **Buy-and-try test:** with free returns, literally weigh it on a kitchen scale; return free if too light.
- **Comfort fit:** Not required — standard fit preferred (for heft)

### Plan B — Custom makers (if Rare Carat arrives flat-topped, not tall)
The DY Beveled Band's raised/faceted cross-section is a specific look mass-market makers mostly don't replicate (that's why DY charges 5x). A custom shop can cut a 7mm band to **exactly** the DY profile — tall crown, sharp bevels. Tradeoff: no try-before-buy; trusting a render/spec.
- **Etsy — 14K Gold Men's Beveled Edge Band** ([listing 1104721415](https://www.etsy.com/listing/1104721415/14k-gold-mens-beveled-edge-wedding-band)): made to order in 5/7/8mm, 10K/14K/18K/Pt, brushed center + polished bevel, free interior engraving. **Must message seller to confirm they can do a TALL/raised profile, not flat-top.** Est. ~$700–1,500.
- **Mociun — Knife Edge Band** ([link](https://mociun.com/products/knife-edge-band)): hand-made NYC, made-to-order, genuinely peaked profile — but tops out at **6mm** ($1,850 14K) and is a thin knife-edge, not a chunky bevel. Would need a custom width request; likely too narrow for the chonky look.
- **General path:** any goldsmith / CustomMade can fabricate a 7mm tall-beveled band to a photo of the DY. Best for an exact match if the off-the-shelf options miss.

**Plan B caveat:** custom = trust the spec, no returns. Only go here if Rare Carat's free-return test fails on height.
