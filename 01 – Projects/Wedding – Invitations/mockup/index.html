What’s new

These are draft options for our invitation, reworked from the stationer’s proof so it matches our wedding website — the same typefaces, the same gold, the same overall feel. What changed from the proof:

•  The website’s fonts throughout — the display face for the names and headers, the Didot serif for body text, and the small caps labels.
•  The “and” is now the gold ampersand from the site, in place of the cursive.
•  The engraved gold border that frames each section of the website now frames each card.
•  The time is corrected — the proof said “five o’clock in the afternoon,” but the ceremony is at six, so it now reads “at six o’clock in the evening.”
•  Kept the pen-and-ink drawing of Casino Español and the map of Centro Histórico.

The only difference between the four options below is how the names are set — everything else is identical, ranging from ornate to clean. Each option is also shown in a black-and-white version, since the final printing may not include the gold.

What we’ll decide together

  1. Which option — A, B, C, or D?

    The only thing that changes is how the names are set, from ornate (A / C) to clean (D). No wrong answer — it’s about the feel we want.

  2. Gold, or black & white?

    The ampersand and border are gold; true metallic gold means foil stamping (costs more, and not every printer offers it). If we print in standard ink or plain black-and-white, each option’s B&W version (linked under each one above) is the fallback — both are ready to compare.

  3. RSVP date — October 1 or October 31?

    The draft currently says “the first of October,” but our planning notes have the deadline as October 31. We should pick one and make the invite, the website, and the RSVP page all agree.
