## 2026-08-01 — Expanded window to May/June + added romance layer

### Situation
- Jonathan: "let's throw may/June into the mix and figure out how to throw in romance." Two asks: (1) expand the timing window beyond March, and (2) inject romance — the framework was all adventure+luxury, light on honeymoon-ness.

### Approach & Rationale — the key insight
- The two asks solve each other: the thing that adds romance is a **warm second leg**, and May/June is exactly when warm legs (beaches, midnight sun) come into season. March never allowed a good romance-leg pairing.
- **Reframed the framework: "extreme meets bougie" → "Adventure → Recovery → Romance,"** delivered as a **two-leg bookend trip**. Bonus: bookend structure hedges the pregnancy question (dial the adventure leg, romance leg always safe).

### What Jonathan Said
- "let's throw may/June into the mix and figure out how to throw in romance"

### Analysis produced (persisted in project note under "Timing + Romance reframe")
- **Seasonality reshuffle for May/June:** Better → Namibia (peak desert), Atacama, Bhutan (May only). Worse → Patagonia (lodges close ~end April), NZ (autumn/winter), Bhutan/Nepal June (monsoon). Unlocked → Iceland/Lofoten/Norway (midnight sun), East Africa (Kili, Rwanda gorillas, June dry), Peru (May/June dry).
- **Bookend concepts:** Namibia + Zanzibar/Mozambique ⭐ (standout — both legs peak May/June, no altitude, is the conceptual model); East Africa classic (Kili/gorillas → beach); Iceland single-country (highlands → Blue Lagoon Retreat); Peru (Machu Picchu → Sacred Valley, altitude caveat); Bhutan + Maldives (May only).
- **Romance set-pieces menu:** balloon+champagne, star bed, heli-picnic, private guide+villa, couples-spa day, overwater closer.
- **Tension flagged:** bookend = ~12–16 days + higher cost; May/June East Africa & Iceland book 9–12 months out, so the 2026-11-01 due is right on time (not comfortable) for June.

### Outputs & State
- Project note: `## Timing + Romance reframe` section added; Overview target-window → **March–June 2027**; framework line updated; booking-deadline note added.
- Tasks: broadened dates task to "window (Mar–Jun 2027) + exact dates" (6h9xRX684mmjM5rF); added new task "Decide trip shape: single destination vs two-leg bookend" (6h9xWhRVQWrfP9Qm). Both synced to Todoist.
