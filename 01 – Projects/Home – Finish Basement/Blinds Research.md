# ADU Basement Blinds — Options to Explore

## Criteria
- Rental-grade durability (easy to replace if damaged)
- Moisture/humidity tolerant (basement)
- Privacy-first (ground-level windows)
- Cordless preferred (cleaner look, tenant safety)
- Standard sizing ideal (same-day replacement from local stores)
- No automation needed

## Option 1: Faux Wood Blinds (2")
Best balance of looks, durability, and cost for a rental.

- **Home Depot — Home Decorators Collection 2" Faux Wood**
  https://www.homedepot.com/b/Window-Treatments-Blinds-Faux-Wood-Blinds/N-5yc1vZbxdo
  - ~$25–45/window (stock sizes)
  - Cordless option available
  - Moisture resistant
  - White or woodtone finishes

- **Lowes — Levolor 2" Faux Wood**
  https://www.lowes.com/pl/Faux-wood-blinds-Blinds-Window-treatments/4294718069
  - ~$30–50/window
  - Cordless, multiple slat colors
  - Good warranty

- **Amazon — Achim Morningstar 2" Cordless Faux Wood**
  https://www.amazon.com/s?k=cordless+faux+wood+blinds+2+inch
  - Budget pick ~$15–30
  - Quick ship, easy returns
  - Quality varies — read reviews per size

## Option 2: Cellular / Honeycomb (Light Filtering)
Better insulation, cleaner modern look. Slightly higher cost.

- **Home Depot — Home Decorators Cordless Light Filtering Cellular**
  https://www.homedepot.com/b/Window-Treatments-Shades-Cellular-Shades/N-5yc1vZbxdp
  - ~$30–55/window
  - Light filtering (not blackout) for living areas
  - Consider blackout for bedroom only

- **Lowes — Levolor Cordless Cellular**
  https://www.lowes.com/pl/Cellular-shades-Shades-Window-treatments/4294718068
  - ~$35–60/window
  - Top-down/bottom-up option for privacy + light

> ⚠️ Note: Cellular shades can trap moisture in humid basements. If the basement has any dampness issues, faux wood is safer.

## Option 3: Roller Shades
Minimalist, cheap, very easy to replace.

- **IKEA — FRIDANS / TRETUR Blackout Roller**
  https://www.ikea.com/us/en/cat/roller-blinds-10102/
  - ~$15–30/window
  - Dead simple, snap-in brackets
  - Limited size options — measure first

- **Amazon — Achim Cordless Roller Shade**
  https://www.amazon.com/s?k=cordless+roller+shade
  - ~$10–25
  - Budget option, easy swap

## Recommendation
**Faux wood 2" cordless from Home Depot or Lowes** — best fit for a rental basement. Moisture-safe, replaceable same-day, looks good enough. Use blackout cellular only for the bedroom if needed.
