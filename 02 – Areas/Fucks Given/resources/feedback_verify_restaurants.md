---
name: Verify restaurants before recommending
description: Always confirm a restaurant is still open before recommending it — check Yelp/Google for closure notices
type: feedback
---

Never recommend a restaurant without first verifying it still exists and is currently open. Check for "permanently closed" notices on Yelp, Google, or the restaurant's own website before including it in any recommendation.

**Why:** Claude recommended Tanglewood Supreme (permanently closed) and Art of the Table (permanently closed) for a celebration dinner. Recommending dead restaurants wastes the user's time and erodes trust in dining recs.

**How to apply:** When searching for restaurant recommendations, always check that each candidate is currently operating before presenting it. This applies to both web search results and entries from the want-to-try list or other vault data files — data can go stale.
